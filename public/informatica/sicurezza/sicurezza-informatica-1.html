// 01 — BRUTE FORCE
Attacco Brute Force:
Di Cosa Si Tratta
Definizione

Un software prova sistematicamente tutte le combinazioni possibili di caratteri finché non trova quella giusta.

Non richiede intelligenza: è pura potenza di calcolo bruta.

È come provare ogni chiave di un mazzo enorme — ma a velocità sovrumana, senza mai stancarsi.

Perché è così efficace
  • Le GPU (schede video) sono ottimizzate per calcoli paralleli
  • Il software non si stanca e non fa errori
  • Servizi cloud affittabili da ~3€/ora
  • Completamente automatico: nessuna supervisione umana
// 01 — BRUTE FORCE
Come Funziona
Passo per Passo
  1. L'attaccante punta a scoprire la password bersaglio provando tutte le combinazioni possibili
  2. Parte dalla prima combinazione: prova "a" → non coincide → prova "b", "c" … "z"
  3. Avanza sistematicamente: finite le lettere singole, prova quelle a due caratteri: "aa", "ab" … e così via
  4. Velocità del computer: oltre 1 miliardo di combinazioni provate al secondo
  5. Password corta a 4 cifre: 10.000 combinazioni → trovata in meno di 1 millisecondo
  6. Password corta a 6 lettere: ~309 milioni di combinazioni → trovata in meno di 1 secondo

// 02 — DATA BREACH
Data Breach:
Cos'è una Violazione dei Dati
Definizione

Un attaccante penetra nei server di un'azienda e sottrae il database degli utenti: email, password, dati personali.

Le password rubate vengono vendute nel Dark Web per pochi euro e usate immediatamente in attacchi automatizzati.

Violazioni Storiche — Numeri Reali
  • Yahoo (2013–14): 3 miliardi di account rubati
  • LinkedIn (2021): 700 milioni di utenti esposti
  • Facebook (2021): 533 milioni di numeri di telefono
  • RockYou2021: 8,4 miliardi di password in un unico file
  • Verifica la tua email: haveibeenpwned.com
// 02 — DATA BREACH
Credential Stuffing:
L'Attacco Automatico
  1. L'hacker acquista il database rubato: milioni di coppie email : password
  2. Avvia un tool automatico che testa quelle credenziali su centinaia di siti diversi
  3. Il tool prova: Gmail, PayPal, Amazon, home banking… tutto in automatico
  4. Se hai usato la stessa password su più siti, tutti vengono compromessi
  5. L'intero processo è completamente automatizzato: milioni di account testati ogni ora
Questo si chiama "Credential Stuffing". Non richiede alcuna abilità tecnica: basta acquistare il file e avviare il software.

// 03 — PASSWORD MANAGER
Password Manager:
La Soluzione al Problema
Senza Password Manager
  • Stessa password su tutti i siti → un breach compromette tutto
  • Password "facili" da ricordare = facili da craccare
  • Password scritte su carta o file di testo non protetto
  • Il cervello non scala: impossibile gestire 80 password complesse
Con Password Manager
  • Password unica e casuale per ogni sito, generata in automatico
  • Es: K#9mP!qRz2Lw@v7N — 16 caratteri, impossibile da indovinare
  • Non la devi ricordare: il software la inserisce in automatico
  • Il vault è cifrato con AES-256: illeggibile senza la master key
// 03 — PASSWORD MANAGER
Come Funziona
Passo per Passo
  1. Scegli una sola Master Passphrase — deve essere totalmente immune sia al Dictionary Attack che al Brute Force (es. galassia-matita-vulcano-salto-92!, 4 parole slegate + separatori + numero)
  2. Il PM usa quella chiave per cifrare un vault (cassaforte digitale) sul tuo dispositivo con AES-256
  3. Per ogni nuovo sito, il PM genera automaticamente una password casuale di 16+ caratteri
  4. Il browser la inserisce in automatico (autofill) — non devi digitarla mai
  5. Se un sito viene violato, solo quella password è esposta — le altre rimangono al sicuro nel vault
🛡️ Perché la Master Passphrase è immune a entrambi?
1. Immune al Dizionario: 4 parole casuali slegate non esistono in nessun file di leak né nel vocabolario.
2. Immune al Brute Force: con oltre 30 caratteri, una GPU impiegherebbe trilioni di volte l'età dell'universo per calcolarla!
PM consigliati (gratuiti):   Bitwarden (open source, cloud)  ·  KeePassXC (open source, solo locale)  ·  Proton Pass (privacy-focused)

I Criteri di Immunità della Master Passphrase
  1. Immunità al Dictionary Attack: non usare mai parole singole, nomi propri, date o sostituzioni note (P@ssw0rd). Usare il metodo Diceware (almeno 4 parole casuali e slegate).
  2. Immunità al Brute Force: la passphrase deve superare abbondantemente i 20 caratteri. Una stringa di 30+ caratteri ha uno spazio combinatorio astronomico (> 10⁴⁵).
  3. Zero-Knowledge: la Master Passphrase non viene mai inviata a nessun server; la decifratura avviene esclusivamente nella memoria RAM del tuo dispositivo.
  4. Facile per l'umano, impossibile per il computer: visualizzare l'immagine mentale di "galassia, matita, vulcano, salto" è immediato per il cervello umano, ma impenetrabile per qualsiasi bot.
⚠ Regola fondamentale: la Master Passphrase è l'unica password che devi ricordare. Non dimenticarla e non condividerla mai!
// 03 — PASSWORD MANAGER: IL GRANDE DUBBIO
Il Grande Paradosso:
"Se il riutilizzo è pericoloso, perché per il PM ne basta una?"
1. La Master Password non viaggia mai su Internet
Siti comuni (E-commerce, Social, Forum): Inserisci la password, il sito la riceve e la salva nei suoi server. Se quel singolo sito viene bucato, la password trapela nel dark web.
Password Manager (Zero-Knowledge): La Master Password serve unicamente a decifrare la cassaforte in locale sul tuo dispositivo. I server del PM non conoscono né vedono mai la tua master password.

▶ La chiave non esce mai dalla memoria del tuo computer: nessun hacker su Internet può intercettarla durante il login.

2. Isolamento dell'Effetto Domino (Stop Stuffing)
Stessa password su 10 siti: Se uno subisce un data breach, gli hacker useranno bot automatici per provare quella combinazione su banche, email e social, violandoli tutti in catena.
Con Password Manager: Ciascuno dei 10 siti ha una password diversa, casuale e lunghissima.

▶ Se il sito X viene bucato, gli hacker possiedono solo la chiave di quel singolo sito; gli altri 9 rimangono blindati e intatti.

// 03 — PASSWORD MANAGER: LA FORTEZZA
La Doppia Protezione:
Crittografia AES-256 & Fattore di Protezione 2FA
3. Crittografia Militare (AES-256)
  • La cassaforte digitale è protetta da AES-256, lo standard crittografico usato da governi e banche.
  • Il file salvato sul dispositivo (o sincronizzato in cloud) è un blocco di byte completamente indecifrabili.
  • Senza la Master Password, anche con tutti i supercomputer del mondo ci vorrebbero miliardi di anni per forzarla.
4. Il Fattore di Protezione 2FA
  • Alla Master Password si affianca l'autenticazione a due fattori (impronta digitale, FaceID o codice TOTP su smartphone).
  • Scenario peggiore: se anche qualcuno scoprisse o spiassse la tua master password mentre la digiti...
  • Senza il tuo secondo fattore fisico (lo smartphone), l'hacker non potrà mai aprire la cassaforte!
💡 Sintesi per lo Studente: Riutilizzare la stessa password moltiplica il rischio per ogni account. Nel Password Manager la Master Password è una chiave locale cifrata e blindata dal 2FA: protegge tutte le altre senza mai rischiare di trapelare.

Autenticazione:
I Tre Fattori Fondamentali
🧠

Qualcosa che conosci

  • Password o PIN
  • Risposta segreta
⚠ Può essere rubato
📱
Fattore 2 — AVERE

Qualcosa che possiedi

  • Smartphone con app TOTP
  • Chiavetta hardware (YubiKey)
✔ Richiede accesso fisico
👁️

Qualcosa che sei

  • Impronta digitale
  • Riconoscimento facciale
✔ Difficile da replicare
2FA = Fattore 1 + Fattore 2. Anche se l'hacker ruba la password (SAPERE), senza il tuo telefono fisico (AVERE) non può accedere.
// 04 — 2FA: IL CODICE TOTP
Come Funziona
il Codice a 6 Cifre

TOTP = Time-based One-Time Password — il codice cambia ogni 30 secondi e non può essere riusato.

  1. Il sito genera una chiave segreta condivisa, trasmessa al tuo telefono via QR code una volta sola
  2. L'app salva questa chiave nel dispositivo (non la invia mai in rete)
  3. Ogni 30 secondi: l'app calcola un nuovo codice a 6 cifre combinando la chiave con l'orario attuale
  4. Il server calcola lo stesso valore e confronta: se coincide → accesso garantito
  5. Il codice scade dopo 30 secondi: anche se intercettato, è inutilizzabile
  6. Senza la chiave nel telefono è impossibile generare il codice corretto
App consigliate: Aegis (Android, open source) · Google Authenticator · Authy · Microsoft Authenticator
⚠ 2FA via SMS è meno sicuro (attacchi SIM Swap). Usare sempre le app TOTP.

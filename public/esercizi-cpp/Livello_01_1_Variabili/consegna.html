Livello 1.1: Telemetria Drone Spaziale

🎯 L'Obiettivo

Il computer di bordo della stazione deve registrare e monitorare i dati di un drone da ricognizione in esplorazione sulla superficie di Marte.

Il tuo compito è dichiarare 4 variabili con i tipi appropriati (stringhe di testo, numeri interi, numeri decimali e valori booleani) e stampare un report di telemetria chiaro sul terminale.

📝 Regole & Requisiti

  • Crea una variabile di tipo std::string chiamata nomeDrone con valore "Scout-X" (richiede #include <string>).
  • Crea una variabile intera int chiamata batteria impostata a 85 (percentuale).
  • Crea una variabile decimale double chiamata velocita impostata a 124.5 (km/h).
  • Crea una variabile logica bool chiamata moduloAttivo impostata a true.
  • Stampa a schermo il report del drone usando std::cout concatenando testo e variabili!

💡 Suggerimenti (Tipi di Dato Utilizzati)

#include <iostream>
#include <string>

std::string nomeDrone = "Scout-X";
int batteria = 85;
double velocita = 124.5;
bool moduloAttivo = true;

📖 Mini-Libreria C++

  • Testo (Stringhe)

    std::string nome = "Testo";
    Sequenza di caratteri racchiusa tra doppie virgolette.

  • Numeri Interi

    int valore = 100;
    Numeri interi positivi o negativi.

  • Numeri con Virgola (Double)

    double vel = 124.5;
    Numeri a virgola mobile ad alta precisione.

  • Booleani (Vero/Falso)

    bool attivo = true;
    Contiene solo true (1) o false (0).

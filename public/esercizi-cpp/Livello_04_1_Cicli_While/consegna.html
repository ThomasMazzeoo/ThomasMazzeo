Livello 4.1: Ricarica Scudi (Ciclo While)

🎯 L'Obiettivo

Dopo una battaglia spaziale, il generatore di scudi energetici della nave è sceso al 20%. Dobbiamo avviare una procedura di ricarica progressiva che aumenti l'energia dello scudo di +20% ad ogni impulso, fino a raggiungere il 100%.

Per eseguire questa sequenza useremo esclusivamente il ciclo while.

📝 Regole & Requisiti

  • Dichiara una variabile int scudo = 20;.
  • Usa un ciclo while (scudo <= 100) che si ripete finché lo scudo non supera il 100%.
  • All'interno del ciclo, stampa la percentuale attuale (es. "Ricarica scudo: 20%").
  • All'interno del ciclo, incrementa la variabile di 20: scudo = scudo + 20; (oppure scudo += 20;).
  • Fuori dal ciclo (al termine), stampa: "SCUDI AL 100%! Sistemi difensivi pronti.".

💡 Suggerimenti (Iterazioni di un Ciclo While)

int scudo = 20;

while (scudo <= 100) {
    std::cout << "Ricarica scudo: " << scudo << "%\n";
    scudo = scudo + 20; // Aggiornamento fondamentale
}

std::cout << "SCUDI AL 100%!\n";

📖 Mini-Libreria C++

  • Ciclo While

    while (condizione) { ... }
    Controlla la condizione all'inizio. Se vera, esegue il blocco e torna a controllare.

  • Passo di Incremento

    scudo += 20;
    Aumenta il valore di 20 ad ogni iterazione.

  • Condizione di Uscita

    <= 100
    Include sia i valori intermedi che il 100 esatto.

Livello 4.5.3: Potenze di Due (< 1000)

🎯 L'Obiettivo

Vogliamo stampare le potenze di due (1, 2, 4, 8, 16...) partendo da 1 e fermandoci appena il valore supera o raggiunge il 1000.

Raddoppiare iterativamente un valore finché è minore di 1000.

📝 Regole & Requisiti

  • Dichiara int potenza = 1;.
    • \n
  • Usa un ciclo while (potenza < 1000).
    • \n
  • All'interno, prima stampa la potenza attuale.
    • \n
  • Poi, raddoppia il valore: potenza = potenza * 2;.

💡 Suggerimenti (Iterazioni di un Ciclo While)

int potenza = 1; while (potenza < 1000) { std::cout << potenza << "\n"; potenza = potenza * 2; }

📖 Focus: Il Ciclo While

  • Sintassi

    while (condizione) { ... }
    Controlla la condizione all'inizio. Se vera, esegue il blocco e torna a controllare.

  • Test di ingresso

    Se la condizione è falsa fin dall'inizio, il ciclo non verrà MAI eseguito, nemmeno una volta.

  • Variabile di controllo

    Assicurati che la variabile usata nella condizione venga modificata all'interno del ciclo, altrimenti creerai un loop infinito.

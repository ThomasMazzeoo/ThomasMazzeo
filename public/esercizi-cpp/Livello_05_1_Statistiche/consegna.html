Livello 5.1: Scanner Risorse (Solo While & Accumulatori)

🎯 L'Obiettivo

Un rover esplorativo sta analizzando diversi giacimenti di cristalli di titanio su un asteroide. Il programma deve leggere la quantità di cristalli trovati in ciascun deposito e calcolare il totale accumulato ed il numero complessivo di depositi scansionati, usando esclusivamente il ciclo while.

La scansione termina quando l'operatore inserisce il valore 0 (valore di arresto / sentinella).

📝 Regole & Requisiti

  • Inizializza int totaleCristalli = 0; e int numeroDepositi = 0;.
  • Inizializza una variabile int cristalli = -1; (un valore diverso da 0 per avviare il ciclo).
  • Usa un ciclo while (cristalli != 0).
  • All'interno del ciclo, chiedi il valore con std::cin >> cristalli;.
  • Se il valore inserito è positivo (if (cristalli > 0)), usa l'accumulatore totaleCristalli += cristalli; e incrementa il contatore numeroDepositi++;.
  • Fuori dal ciclo, stampa a schermo il resoconto completo dei depositi e dei cristalli estratti!

💡 Suggerimenti (Il Pattern Sentinella nel While)

int totaleCristalli = 0;
int numeroDepositi = 0;
int cristalli = -1;

while (cristalli != 0) {
    std::cout << "Inserisci cristalli (0 per fine): ";
    std::cin >> cristalli;
    if (cristalli > 0) {
        totaleCristalli += cristalli;
        numeroDepositi++;
    }
}

📖 Mini-Libreria C++

  • Ciclo While con Sentinella

    while (valore != 0) { ... }
    Continua a richiedere input finché l'utente non inserisce il valore di stop (0).

  • Accumulatore

    totale += x;
    Aggiunge x al totale cumulativo in RAM.

  • Contatore

    conteggio++;
    Conta quante iterazioni valide sono state elaborate.

Livello 5: Accumulatori, Contatori e Do-While

🎯 L'Obiettivo

Nel Livello A ti è stato richiesto di "contare" il totale delle squadre e "sommare" i punteggi globali. Inoltre hai dovuto gestire un menu interattivo. Queste sono tecniche fondamentali che studieremo formalmente in questo livello: le scorciatoie matematiche e il Ciclo Do-While.

📝 1. Contatori (++) e Accumulatori (+=)

Nel Livello 4 scrivevamo conto = conto - 1;. I programmatori sono pigri, quindi in C++ esistono delle scorciatoie:

  • Contatori: Per aumentare una variabile di 1 si scrive semplicemente variabile++;. (Per diminuire si usa --).
  • Accumulatori: Per sommare un valore ad una variabile si usa totale += valore; (che è identico a scrivere totale = totale + valore;).

🔄 2. Il ciclo Do-While

Il while normale controlla la condizione prima di eseguire il codice. A volte però vogliamo che il codice venga eseguito almeno una volta (ad esempio, per mostrare un menu o chiedere il primo input) e solo dopo controllare se ripetere.

int scelta;
do {
    std::cout << "Premi 1 per ripetere, 0 per uscire: ";
    std::cin >> scelta;
} while (scelta != 0); // Il controllo è alla FINE!

🎮 L'Esercizio: Il Raccoglitore d'Oro

  • Inizializza totaleOro = 0 e numeroBauli = 0.
  • Usa un do-while che chiede all'utente quante monete ci sono nel baule appena aperto.
  • All'interno del ciclo usa l'accumulatore += per aggiungere l'oro trovato al totaleOro.
  • All'interno del ciclo usa il contatore ++ per incrementare di 1 il numeroBauli aperti.
  • Il ciclo deve ripettersi finché l'utente inserisce un valore diverso da 0 (0 significa "non ci sono più bauli").

📖 Mini-Libreria C++

  • Ciclo Do-While

    do { ... } while (x != 0);
    Esegue il blocco PRIMA di controllare la condizione. Utile per i menu! Ricorda il ; alla fine.

  • Accumulatori

    totale += oro;
    Scorciatoia elegante per scrivere totale = totale + oro;.

  • Divisione con Decimali

    Se dividi due int, il C++ taglia i decimali. Usa (float) davanti a una variabile per forzare il risultato decimale.

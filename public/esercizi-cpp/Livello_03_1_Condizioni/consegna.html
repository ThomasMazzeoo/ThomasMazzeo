Livello 3.1: Monitor Reattore a Fusione

🎯 L'Obiettivo

Sulla nave stellare, il reattore a fusione nucleare deve operare entro un intervallo termico sicuro. Dobbiamo programmare un sistema di diagnostica a tre stati utilizzando if, else if ed else.

📝 Regole & Requisiti

  • Dichiara una variabile intera int temperatura;.
  • Chiedi all'utente di inserire la temperatura attuale del reattore in gradi °C tramite std::cin.
  • Se la temperatura è maggiore di 100 (temperatura > 100), stampa: "ALLARME: Sovraccarico termico!".
  • Altrimenti se la temperatura è minore di 20 (temperatura < 20), stampa: "ATTENZIONE: Temperatura insufficiente!".
  • In tutti gli altri casi (tra 20 e 100 compresi, blocco else), stampa: "STATO NORMALE: Reattore stabile.".

💡 Suggerimenti (If / Else If / Else)

Quando ci sono più di due possibili scenari mutuamente esclusivi, usiamo else if in cascata:

if (temperatura > 100) {
    std::cout << "Allarme critico!\n";
} else if (temperatura < 20) {
    std::cout << "Temperatura bassa!\n";
} else {
    std::cout << "Tutto regolare.\n";
}

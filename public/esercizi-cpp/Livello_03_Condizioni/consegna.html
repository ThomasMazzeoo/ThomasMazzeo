Livello 3: Condizioni (If / Else)

🎯 L'Obiettivo

L'intelligenza vera di un software risiede nella sua capacità di prendere decisioni in base ai dati che riceve. Nel videogioco, cosa succede se la salute del personaggio scende a zero? Dobbiamo mostrare il "Game Over"!

Il tuo obiettivo è chiedere all'utente quanta salute gli è rimasta e comportarti di conseguenza.

📝 Regole & Requisiti

  • Chiedi all'utente di inserire i suoi Punti Vita (HP) tramite cin.
  • Usa il costrutto if per controllare se i Punti Vita sono minori o uguali a 0.
  • Se la condizione è vera, stampa "Sei morto! GAME OVER.".
  • Altrimenti (usando else), stampa "Sei ancora vivo! Continua a combattere.".

💡 Suggerimenti (Operatori di Confronto)

All'interno delle parentesi tonde dell'if devi fare una domanda al computer che possa avere solo due risposte: VERO (true) o FALSO (false).

if (salute <= 0) {
    // Questo blocco si esegue SOLO se la domanda è VERA
} else {
    // Questo blocco si esegue SOLO se la domanda è FALSA
}

Altri operatori utili: == (è uguale?), != (è diverso?), > (maggiore), < (minore). Attenzione a non confondere il doppio uguale == (confronto) col singolo uguale = (assegnazione)!

Livello 4.5.2: Indovina il Numero Segreto

🎯 L'Obiettivo

Un sistema di sicurezza richiede un codice di sblocco segreto (es. 42). Dobbiamo continuare a chiederlo in input finché non viene indovinato.

Continuare a chiedere un tentativo finché non si indovina il numero.

📝 Regole & Requisiti

  • Dichiara int segreto = 42; e int tentativo = 0;.
    • \n
  • Usa un ciclo while (tentativo != segreto).
    • \n
  • All'interno, chiedi 'Inserisci codice di sblocco: ' e leggi il tentativo.
    • \n
  • Quando l'utente inserisce 42, esci dal ciclo e stampa 'Accesso Consentito!'.

💡 Suggerimenti (Iterazioni di un Ciclo While)

int segreto = 42; int tentativo = 0; while (tentativo != segreto) { std::cout << "Inserisci codice di sblocco: "; std::cin >> tentativo; } std::cout << "Accesso Consentito!\n";

📖 Focus: Il Ciclo While

  • Sintassi

    while (condizione) { ... }
    Controlla la condizione all'inizio. Se vera, esegue il blocco e torna a controllare.

  • Test di ingresso

    Se la condizione è falsa fin dall'inizio, il ciclo non verrà MAI eseguito, nemmeno una volta.

  • Variabile di controllo

    Assicurati che la variabile usata nella condizione venga modificata all'interno del ciclo, altrimenti creerai un loop infinito.

Livello 4.5.4: Password Sicura

🎯 L'Obiettivo

L'utente deve registrare una nuova password. La password deve essere lunga almeno 8 caratteri. Finché inserisce password troppo corte, il sistema continua a rifiutarle.

Continuare a richiedere l'inserimento finché la stringa non è lunga almeno 8 caratteri.

📝 Regole & Requisiti

  • Dichiara std::string password = ""; (assicurati di includere <string>).
    • \n
  • Usa un ciclo while (password.length() < 8).
    • \n
  • Dentro il ciclo chiedi all'utente di inserire la password.
    • \n
  • Alla fine, se la lunghezza è ≥ 8, il ciclo si interrompe e stamperai 'Password salvata.'

💡 Suggerimenti (Iterazioni di un Ciclo While)

#include <string> // ... std::string password = ""; while (password.length() < 8) { std::cout << "Inserisci password (min 8 car): "; std::cin >> password; } std::cout << "Password salvata.\n";

📖 Focus: Il Ciclo While

  • Sintassi

    while (condizione) { ... }
    Controlla la condizione all'inizio. Se vera, esegue il blocco e torna a controllare.

  • Test di ingresso

    Se la condizione è falsa fin dall'inizio, il ciclo non verrà MAI eseguito, nemmeno una volta.

  • Variabile di controllo

    Assicurati che la variabile usata nella condizione venga modificata all'interno del ciclo, altrimenti creerai un loop infinito.
